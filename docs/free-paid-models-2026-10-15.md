# Общий каталог и маршрутизация моделей, 15 октября 2026

## Контракт

- `/api/models`: разрешённые Bedrock и OpenRouter в одном списке для аккаунта с API-бюджетом; обычному аккаунту — только проверенные нулевые `:free`. Ошибка OpenRouter не убирает разрешённый Bedrock.
- `arni_provider`, `arni_free`, `arni_cache` дополняют стандартные цены и `architecture.input_modalities`; кэш — возможность, не обещание попадания.
- `/chat/completions`: выбранный OpenRouter ID направляется в OpenRouter, Bedrock ID проверяется по личным/глобальным разрешениям. Настройка `llmProvider` выбирает предпочтение по умолчанию, а не принудительный маршрут всех запросов.
- Бесплатные запросы используют `reserveFreeStep`, включая аккаунты с бюджетом. Бюджет не резервируется; отключение, истечение или обнуление денежного доступа не блокирует бесплатный маршрут. Бан аккаунта сохраняется.
- Сервер проверяет нулевые цены в каталоге и задаёт нулевой `provider.max_price`. Автоматическая замена остаётся бесплатной и сохраняет требование поддержки изображения. Неизвестный ID не вызывается.
- Изображения только встроенные PNG/JPEG с прежними ограничениями размера, количества и ролей. URL сервер не загружает. Платные OpenRouter-модели проверяются по каталогу на vision, ставки и ценовые уровни.
- Резерв платного OpenRouter учитывает верхнюю опубликованную ступень и image/cache-тарифы; расчёт использует `usage.cost`. Если точной стоимости нет, запись помечается `estimated`.
- `prompt_tokens_details.cache_write_tokens` нормализуется в общий счётчик cache write; сохранены request ID, chat ID, фактическая модель и источник расчёта.
- Явные cache markers OpenRouter добавляются только документированным Anthropic/Alibaba IDs; для Qwen VL через Bedrock маркер не добавляется. Статический префикс сохраняется без изменения пар tool calls/results.

## Проверка

`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-billing.ps1` создаёт одноразовую локальную PostgreSQL и использует заглушки AWS/OpenRouter. Проверены: общий каталог, free vision на BEDROCK-аккаунте с отключённым/просроченным бюджетом, платный vision и фактическое USD списание, отказ неизвестной/не-vision модели до upstream, отдельная бесплатная квота, нулевые тарифы и кэш. Production DB этот тест не затрагивает. Типы проверяются локальным `tsc --noEmit --incremental false`.

Реальный тест видео пользователя: 17 обращений, 705184 input / 1453 output, $0.377621; изображения модели не передавались. Видео имело только 1 кадр из-за незакольцованного фона и overlay shortest=1. Это наблюдение о конкретном прогоне, не бенчмарк всех Qwen.

Клиентская инструкция и матрица следующего теста: репозиторий arni-code, `docs/releases/2026-10-15-free-paid-models.md`. Результаты провайдеров и выпуска фиксировать отдельно от локальных заглушек.

Источники кэша: [OpenRouter](https://openrouter.ai/docs/guides/best-practices/prompt-caching), [Bedrock](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html).
